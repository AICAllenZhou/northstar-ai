# NORTHSTAR AI — Data Provenance

Rule: every number shown in the application is either traceable to a named
public source or labelled synthetic. Synthetic operational data is never
presented as real Canadian aviation data. The machine-readable record of
every raw download (URL, licence, retrieval time, SHA-256, size) is
`datasets/raw/PROVENANCE.json`. Each processed file has a `*.meta.json`
sidecar generated by `scripts/build_datasets.py`.

## 1. Real public data

| What | Source | Licence | File(s) |
|------|--------|---------|---------|
| Airport identity, IATA/ICAO codes, coordinates, elevation for 28 airports | OurAirports `airports.csv`, retrieved 2026-09-24 | Public domain (Unlicense), https://ourairports.com/data/ | `datasets/raw/ourairports/selected_airports.csv` → `datasets/processed/airports.csv` |
| Runway length and surface (longest open runway) for 26 of 28 airports | OurAirports `runways.csv`, retrieved 2026-09-24 | Public domain | `datasets/raw/ourairports/selected_runways.csv` |
| Runway length and surface for Grise Fiord (CYGZ) and Kimmirut (CYLC); surface for Whale Cove (CYXN) and Chesterfield Inlet (CYCS) | **Secondary source:** Wikipedia airport infoboxes, which cite the Canada Flight Supplement. OurAirports has no runway rows for CYGZ/CYLC and records surface `UNK` for CYXN/CYCS. | CC BY-SA (Wikipedia text); the underlying facts are from Nav Canada's CFS | `datasets/raw/supplements/runway_supplement.csv`; flagged per airport in the `data_flags` column of `airports.csv` |
| 2021 Census population for 25 Nunavut communities plus Yellowknife, Winnipeg, Ottawa | Statistics Canada, 2021 Census of Population, table 98-10-0002-01 (census subdivisions), downloaded 2026-09-24 | Statistics Canada Open Licence, https://www.statcan.gc.ca/en/reference/licence | `datasets/raw/statcan/population_2021.csv` (with DGUIDs) → `communities.csv` |
| Basemap: country, province/territory and lake polygons | Natural Earth 1:50m vectors (`ne_50m_admin_0_countries`, `ne_50m_admin_1_states_provinces_lakes`, `ne_50m_lakes`) | Public domain, https://www.naturalearthdata.com/about/terms-of-use/ | `datasets/processed/basemap/*.geojson` (filtered to North America / Canada, coordinates rounded to 3 dp) |

Notes on the real data:
- Sources use legacy names for three communities. The application shows the
  current official names (Kinngait for Cape Dorset, Sanirajak for Hall Beach,
  Naujaat for Repulse Bay) and keeps the source names in the raw files.
- Community coordinates are the airport coordinates. In every one of these
  communities the airport is within a few kilometres of the settlement, which
  is adequate for a network-scale map.
- Route distances are great-circle distances computed from the real
  coordinates; they are derived, not measured.
- Full raw downloads over ~2 MB are not committed to git; their SHA-256 hashes
  are recorded so anyone can re-download and verify. The extracts actually
  used (`selected_*.csv`, `population_2021.csv`, filtered GeoJSON) are committed.

## 2. Synthetic data (assumptions)

| What | Why synthetic | Where declared |
|------|---------------|----------------|
| Hub roles (medical / cargo / passenger hubs at Iqaluit, Rankin Inlet, Cambridge Bay, Yellowknife, Winnipeg, Ottawa) | Informed by public knowledge of regional hospitals and airline hubs; not an official designation | `airports.csv` columns `is_*_hub`, `hub_note`; `airports.meta.json` |
| Route network (41 undirected routes) | Hub-and-spoke simplification informed by publicly advertised Northern airline networks; not an official schedule or airway structure | `scripts/build_datasets.py` `ROUTES`; `routes.meta.json` |
| Fleet of 10 aircraft: composition, home bases, availability, cost index | Real aircraft types (Twin Otter, ATR 42, Dash 8-300, King Air 350, PC-12, 737-200 combi) with rounded approximations of public specifications. Fleet composition and basing are invented. Not for operational use. | `aircraft.csv`; `aircraft.meta.json` |
| Daily passenger schedule (26 legs) and passenger counts | Invented one-day schedule to give the network a normal state to disrupt | `schedule.csv`; `schedule.meta.json` |
| Base weather and wildfire risk values | Constant placeholders consumed by the transparent risk score | `airports.csv` |
| Community priority weights | Equal (1.0) by default; see `RESPONSIBLE_AI.md` for why population weighting is not the default | `communities.csv` |
| Disruptions, medical emergencies, cargo requests | Generated by presets or the seeded scenario generator | `northstar/scenarios/` |
| Medical response target (240 min), turnaround (30 min), cargo deadline default (8 h) | Simulation parameters, declared in `northstar/config.py` | `config.py` |

## 3. Reproducing the datasets

```
python3 scripts/build_datasets.py     # rebuilds datasets/processed/ from datasets/raw/
```
The script refuses to run if any airport lacks a runway length rather than
guessing one. Re-downloading the raw files is described in
`datasets/raw/PROVENANCE.json` (URLs and expected hashes).

## 4. What is deliberately not included

No live data feeds are used in the MVP (no weather, no wildfire hotspots, no
ADS-B). The data contract has `weather_risk` and `wildfire_risk` fields per
airport so that a public feed (MSC GeoMet, CWFIS) could populate them later as
an optional enhancement layer, without changing the simulation.
